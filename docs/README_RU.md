# File Integrity Monitor — руководство на русском

FIM проверяет только выбранные вами папки. Приложение создаёт исходную базу SHA-256 и записывает добавленные, изменённые и удалённые файлы в SQLite. Доступны ручная проверка, мониторинг watchdog, пауза, история и экспорт JSON/CSV.

## Установка

Нужен Python 3.12. Создайте окружение командой `python -m venv .venv`, активируйте его, затем выполните `python -m pip install -r requirements.txt` и `python main.py`. В Linux при ошибке Qt XCB установите через пакетный менеджер `libgl1`, `libegl1`, `libx11-xcb1`, `libxcb-cursor0`, `libxkbcommon-x11-0`, `libdbus-1-3`. В PowerShell активируйте окружение командой `.venv\Scripts\Activate.ps1`.

## Использование

Выберите папку, создайте исходную базу и запустите ручную проверку либо мониторинг. События показывают время UTC и путь. После паузы продолжение запускает новую проверку. Сохраните итог последней проверки и события в JSON или CSV с панели. Язык выбирается справа вверху и сохраняется после перезапуска.

База данных и журнал предупреждений находятся в системном каталоге данных приложения. Содержимое файлов не сохраняется. Пути и хеши в отчётах могут быть конфиденциальными — проверьте отчёт перед публикацией.
