# Changelog

## 1.0.0 — 2026-10-12

- Initial PySide6 desktop application with three languages.
- SHA-256 baseline and added/modified/deleted detection.
- SQLite history, watchdog monitoring, pause/resume and JSON/CSV export.
- Automated tests, Linux/Windows CI packaging, verified Linux startup and multilingual documentation.
- Guards for incomplete scans, symlinks, special files, CSV formulas and internal database files.
